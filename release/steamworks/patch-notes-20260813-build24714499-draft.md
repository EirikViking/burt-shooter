# Nova Swarm — Clearer Command, Better Combat Feedback

Status: staged for publication; not published

This update makes Nova Swarm easier to read, faster to enter, and cleaner during the most intense runs.

## A clearer first launch

- The main menu now gives new pilots one obvious way into the action, with a prominent `START PLAYING` call to action and an animated guide arrow.
- Pilot Orders no longer crowd the main menu. Their progress remains available in the Hangar and during the run.
- Menu typography, spacing, focus frames, button alignment, and compact layouts have been reworked across the main menu, Hangar, leaderboards, Settings, How to Play, and run briefings.
- The Music control now stays aligned with the other top-right utilities.

## Combat and boss reliability

- Boss warnings now have an explicit lifecycle: interrupted attacks cleanly cancel their warning, aim lock, audio, and visuals before any new attack can begin.
- Pause freezes a visible boss warning, and long frames can no longer release a stale attack without a full warning.
- Sky Verdict now resolves Bomb damage first, tracks the surviving target, can reacquire once, and refunds its reserved charge if no valid target remains.
- Cabinet Wonders now pause timed effects and wave progression throughout the no-control presentation, with a larger and more readable reveal.
- Harsh long-tailed explosion layers were removed from routine enemy deaths, reducing the hiss/static that could build up during dense Overrun fights.

## Better run information

- Run Reports now show both `ACTIVE TIME` and `TOTAL ELAPSED`. Competitive records continue to use Active Time only.
- Ship veteran progress is now presented as `TOURS`: one legitimate ten-sector flight in Mayhem, Overrun, or Sector Run. Ranked Bronze, Silver, and Gold mastery medals remain separate.
- Tactical pilots can tap Pass to skip one Draft, or hold Pass to lock the current build and stop all later Drafts for that run.
- Cabinet Skill Flight targets now read as unmistakable holograms, with `CONTACT SAFE` messaging in the HUD and How to Play.

## Leaderboards

- Leaderboard views now support a readable Top 50 with clear paging, larger pilot names, prominent rank emblems, and a corrected 10-row compact layout.
- Verified Steam pilots remain clearly separated from presentation-only CPU rivals; CPU entries never submit, qualify, persist, or affect Steam ranks.

## Polish and compatibility

- All new player-facing text is localized across the eight supported interface languages.
- Keyboard, mouse, and controller flows were rechecked across menus, Tactical Drafts, Hangar launch, and result screens.
- The experimental late-game mode remains unchanged.
