# Nova Swarm Asset Extras Summary

The current asset upgrade path is public-release oriented:

- Generated cinematic intro panels and arcade backdrops support the story intro and menu.
- Generated comms portraits replace any legacy real-person photo concept.
- Generated Steam capsules, screenshots, and trailer material are tracked under `release/`.
- Ship and enemy variety is handled through public arcade variants with stable hitboxes.
- Audio polish uses original SFX, narration, and music contexts with release mix checks.

Run `npm run check:provenance` and `npm run audit:release-readiness` after any asset-extra change.
