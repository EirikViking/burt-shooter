# Solid player fleet and continuous menu ambience

Baseline: `c9413224e94b45a728daa73e016b2e161b8c018f` on `codex/astra-visual-overhaul`, uniquely owned by `D:\vibe-coding-e\nova-swarm-forum-129-improvements-20260822`. Fetch, branch, log, clean status and worktree ownership were verified before changes. The checked-out version is the baseline. Earlier drones, snakes, core rewards, menu buttons and community decisions are preserved.

The user rejected the relief/height-map fleet. Thirty original Blender-authored solid meshes replace that approach. Each has an individually specified architecture, closed volumetric fuselage, modeled engines and underside, separated armor, deliberate livery, weapons, machinery and emissive materials. Original ship art informs colors and personality; exact silhouette copying was not required. Stats, traits, collision radii and unlock requirements are unchanged. GLBs contain no raster hull textures. The same models supply gameplay sprites and lossless showroom portraits. Reproduction: Blender background with `scripts/build-solid-fleet.py -- player 30 0`, then `node scripts/finalize-solid-fleet.mjs`. Editable masters and hash manifest are in `docs/solid-fleet-20260908/`.

`AstraTurntable` now uses live Three.js GLBs through the existing Pixi scene graph. A single shared WebGL renderer serves the selected ship; models and shadow resources are released when selection changes or menus close. Normal close-up resolution is 1536 square, increasing for large windows up to 2560; Hangar cards use 768. Static views do not render again until their angle changes. Horizontal and vertical drag inspect actual geometry; there is no low-resolution atlas swap while dragging. Matching rendered portraits provide a fallback if WebGL/model loading fails. No external generation service or new audio generation was needed.

Menu audio is owned by scene routing. Main menu, Hangar, ship details, achievements, leaderboard and Codex share the existing four ElevenLabs ambience stems without stopping/restarting them. The old Hangar call that started gameplay music was removed. Gameplay music starts only after a successful transition to Play; rejected launches cannot leave normal songs running in a menu. A stale fade callback cannot pause a newer gameplay context, and queued song starts cannot enter an ambient context.

Menu voices default off. The localized Audio toggle is present in all eight languages, gates even force/ignore-global-voice requests in menus, stops active/delayed menu voices immediately when disabled, and persists through the existing local/Cloud save schema. Global voice and boss voice preferences remain separate. The existing ElevenLabs ambience recordings and game sounds are unchanged; no synthesized replacement sounds were added.
