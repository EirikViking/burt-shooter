# Nova Swarm Patch Notes Draft - Ultra-Hard Achievements

Draft date: 2026-06-15

## Headline

Ultra-hard achievement chase added

## Steam News Draft

This update expands Nova Swarm's achievement chase with 10 new ultra-hard legendary goals for pilots who want something rude to hunt after the basics are done.

New goals cover deep overrun sectors, two-million-point scoring, long no-hit streaks, heavy boss clears, 200-hit combo play, danger-dodge chains, Graze Break mastery, and the full 25-ship hangar.

Also included:

- New achieved and locked badge art for each ultra-hard achievement.
- Updated achievement validation so the full source catalog now covers 81 achievements.
- Fresh Steamworks setup export for verifying every achievement API name and icon in App Admin.

Notes:

- Existing achievement API names were not renamed.
- Leaderboard identity remains `nova_swarm_global_score_v2`.
- Steamworks achievement rows must be verified in App Admin before every new achievement appears in the Steam client.
