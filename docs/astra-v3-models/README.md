# Astra third-pass production sources

Original artwork created for this local Nova Swarm experiment. The actual game uses the normalized files under `public/art/astra/`; this directory preserves editable Blender scenes, original generated inputs, prompts and registration receipts.

## Reproduce the accepted assets

Run from the repository root with the installed Node runtime. Blender executable used: `test-results/astra-tools/blender-4.5.4-windows-x64/blender.exe`.

1. `blender -b -t 5 --python scripts/render-astra-turntable.py -- turntable 30 0 72`, then `node scripts/pack-astra-turntables.mjs 0 30`. This creates 72 real orbit renders for each of 30 hulls. The main atlas uses 768-pixel views, other hulls 384 pixels. Only selected ship atlases remain resident. Lighting is baked in Blender; the runtime adds limited reflections and engine light. Drag rotates through the rendered views, rather than running a 3D engine.
2. `node scripts/pack-astra-generated-threats.mjs FAMILY` followed by `node scripts/pack-astra-threats.mjs FAMILY`, where FAMILY is `supports`, `elites`, `late` or `boss`. The original sheets are preserved; these steps only normalize and register them against the original gameplay canvases. Receipts preserve every original alpha footprint.
3. `node scripts/pack-astra-dossiers.mjs` creates clean enlarged codex art from the accepted sources. Registered gameplay sprites keep their original dimensions; the codex uses separate high-resolution images.
4. `node scripts/pack-astra-reactor-burst.mjs` packs the accepted 16-frame reactor burst into a 1536-square atlas. `render-astra-detonation-v3.py` is an editable rejected Blender prototype, retained for continuity; it is not the shipped explosion.

The support roster uses eight role designs plus the separate reactor nurse; 50 elites use twelve archetype paintings, 177 late-enemy slots use sixteen paintings, and 50 bosses use ten archetype paintings. These are coherent art families, not hundreds of bespoke painted designs. Identities, names and mechanics remain the original catalog's. The separate turret module is from boss sheet 3.

`player-paint-01.png` was generated by editing a render of the existing hull. Its opaque backing is unsuitable for a cutout; it is used only as a masked Blender surface projection onto existing geometry. `hull-skin.png` supplies manufactured surface detail. Shape, depth, camera and actual turntable lighting come from the editable models. Small registered gameplay player sprites retain the preceding pass's modeled art.

The three original environment plates are normalized to 2048x1152. The preceding pass's 48 planetary environments remain, changing every five sectors through Sector 240 and then cycling.

Visual QA captures are actual game images under task-local `test-results/`, not these source renders. All test profiles and platform transport are isolated. Production saves, Steam Cloud, achievements and live leaderboards were not used.
