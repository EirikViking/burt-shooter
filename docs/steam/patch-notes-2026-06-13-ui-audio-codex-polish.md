# Nova Swarm Patch Notes - June 13, 2026

Status: post-ready Steam announcement/forum copy.

## Suggested Title

Nova Swarm Patch Notes: Clearer UI, Meaner Bosses, Louder Runs

## Steam/Forum Body

Hi pilots,

This patch is another early-feedback cleanup pass. The goal is simple: keep the chaos loud, make the important stuff easier to read, and make every run feel a little harder to walk away from.

[h2]What Changed[/h2]

[list]
[*]Cleaned up the main menu so Launch Run and Sector Start are easier to understand.
[*]Improved the pause menu with stronger sci-fi presentation and cleaner focus states.
[*]Tidied the top-left gameplay HUD so score, rank, level, and high-score chase info are easier to scan.
[*]Reduced duplicate/noisy combo messaging.
[*]Improved Codex readability and started moving entries toward more story-driven descriptions.
[*]Expanded Sonia and KurtBossEdgar boss lore.
[*]Improved generated enemy visuals and late-run readability.
[*]Fixed boss death voice priority so dramatic boss-death audio is not buried by other voice lines.
[*]Added rare alien attack barks so enemies sound more alive without turning combat into voice spam.
[*]Added high-score chase prompts so the game keeps reminding you what number is judging you.
[*]Added selectable Overdrive soundtrack options in Settings.
[/list]

[h2]Still Being Staged[/h2]

The game-side achievement catalog has been expanded, but Steam achievement metadata is still being staged in Steamworks. If Steam shows fewer achievements than the game code supports, that is the Steam backend list catching up, not your save file breaking.

[h2]Keep Sending Notes[/h2]

The early pilot feedback has been sharp and useful. If something looks messy, sounds wrong, feels unfair, or makes a run feel off, keep sending screenshots. That is how this thing gets better.

Thanks for playing,
Tiny Foundry
