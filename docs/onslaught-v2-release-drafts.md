# Onslaught v2 release copy (draft only)

These drafts are for review after the packaged test build passes. Do not publish them with the unpublished Steamworks achievement schema.

## Private test branch notes

Onslaught Tactical now lets you choose a ship and three starting augments before launching at Sector 51. It starts at zero score, grants full career XP for earned play, and submits compatible results to a new global leaderboard. Retry with the same build, change your loadout, or inspect another pilot's recorded starting build. Arcade remains the first choice on the main menu. Onslaught's Space Snake encounters have shorter attack windows and more purposeful cycles; Arcade tuning is unchanged. The results screen now keeps its actions visible and separates this run, your best, and confirmed Steam status.

The new achievement catalog and localization are staged separately and require a coordinated public schema release. The 19 new Onslaught achievements are not advertised as live in this test build.

## Store/update note after coordinated public release

Build an Onslaught run your way: choose a ship, select three starting augments, and launch into Sector 51. Earn boss upgrades in play, compare your score on the separate Onslaught Tactical board, and inspect recorded starting builds for ideas. Arcade Tactical remains the welcoming first flight. Eligible earned career XP and achievements count under each mode's stated rules; skipped sectors and supplied equipment never grant progress.
